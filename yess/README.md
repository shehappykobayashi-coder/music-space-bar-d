# yess 公式サイト（制作中）

依存パッケージなし・ビルド不要の静的サイトです。`yess/` ディレクトリをそのまま公開できます（Cloudflare Pages / Vercel / GitHub Pages など）。

- ローカル確認: `cd yess && python3 -m http.server` → http://localhost:8000
- 点線の枠で「要提供」と表示している箇所は未確定情報です。差し替えるまで公開しないでください。
- 公開前に `index.html` の `<meta name="robots" content="noindex, nofollow">` を削除してください。

## 画像
- `assets/img/logo-*.png` … 支給ロゴ（JPG）から切り出したもの。元データ（SVG/AI）が届いたら差し替えてください。
- `assets/img/waraino-*` … 「ワライノガッコー」の写真。1・2枚目は、投影資料に著作権表示と個人情報が含まれるため、スクリーン部分をぼかし処理しています。
